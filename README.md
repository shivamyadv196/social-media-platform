# Social media platform

A modern social media platform built with the MERN Stack that allows users to share posts, interact through likes and comments, manage profiles, receive notifications, and communicate via real-time messaging.

## ✨ Features

- User Authentication & Authorization
- Create, Like, Comment, and Delete Posts
- Profile Management
- Bookmark Posts
- Suggested Users
- Real-Time Chat
- Real-Time Notifications
- Responsive User Interface
- Secure JWT Authentication

## 🛠️ Tech Stack

### Frontend
- React.js
- Redux Toolkit
- Tailwind CSS
- Shadcn UI
- Axios
- React Router DOM

### Backend
- Node.js
- Express.js
- MongoDB
- Mongoose

### Other Technologies
- Socket.IO
- JWT Authentication
- Cloudinary
